Multiplication Table

Hover or tap any cell to see the multiplication. Notice the patterns — like the diagonal of squares (1, 4, 9, 16, 25…).

👆 Tap a cell

Cool patterns to discover

  • Diagonal: 1×1, 2×2, 3×3, 4×4... gives square numbers (1, 4, 9, 16, 25, 36...).
  • 2× row: doubles each number — 2, 4, 6, 8, 10, 12...
  • 5× row: ends in 0 or 5 — 5, 10, 15, 20, 25...
  • 10× row: just add a zero — 10, 20, 30, 40...
  • 9× row: the digits add up to 9 — 9, 18 (1+8=9), 27 (2+7=9)...
  • Symmetry: 3×4 = 4×3 = 12. The table is a mirror!
