How to add

Adding means putting things together. If you have 3 apples and someone gives you 2 more, you count all of them: 1, 2, 3, 4, 5. So 3 + 2 = 5.

Tip: You can add in any order. 3 + 2 is the same as 2 + 3. Both equal 5.
