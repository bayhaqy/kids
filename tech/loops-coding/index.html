Loops & Patterns

See how loops draw shapes.

📚 Lessons

🔁

A loop tells the computer to do something again and again. Save time, write less code!

🔄

A "for loop" runs a set number of times. "Repeat 4 times: draw a line and turn 90°" — makes a square!

♾️

A "while loop" runs while something is true. "While game is not over: keep playing".

🌈

Loops can draw spirals, flowers, stars. Try changing the angle and number of repeats!

⚙️

Nested loops: a loop inside a loop. Like rows and columns in a grid. Powerful!
